# IA no meu fluxo

Uso o Claude Code — a CLI de IA da Anthropic — como par de programação no dia a dia, dos meus projetos em produção a este próprio portfólio. Não é atalho para pular o aprendizado: é a ferramenta que me deixa iterar mais rápido, revisar meu código com mais rigor e entregar mais em menos tempo. Todo código que eu entrego, eu leio, entendo e sei defender.

01 — dia a dia

Claude Code no dia a dia

Par de programação real: implementação de features, refatoração, caça a bugs e code review. A IA propõe, eu avalio, testo e decido o que entra no projeto.

02 — contexto

Engenharia de contexto

Sei fornecer o contexto certo ao agente — arquivos relevantes, convenções do projeto e regras em CLAUDE.md / AGENTS.md — para obter resultados consistentes em vez de código genérico.

03 — automação

Fluxos agênticos

Configuro e opero ferramentas agênticas: CLIs próprias, skills e slash commands que automatizam etapas repetitivas do meu processo de desenvolvimento.

04 — julgamento

Revisão crítica sempre

IA acelera, não substitui julgamento. Nada vai para produção sem eu ler, testar e entender — inclusive as implicações de segurança e performance.
